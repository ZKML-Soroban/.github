# Support

Thanks for using ZKML Soroban. Use the channel that matches your need so it reaches the right
place quickly.

| Need | Where to go |
| ---- | ----------- |
| Usage questions and how-tos | Read the [documentation](https://github.com/ZKML-Soroban/ZKML-Soroban/tree/main/docs) first, then open an issue with the `question` label. |
| Bug reports | Open an issue using the bug report template. Include versions, steps to reproduce and logs. |
| Feature ideas | Open an issue using the feature request template and describe the use case. |
| Security vulnerabilities | Do not open a public issue. Report privately as described in the [security policy](https://github.com/ZKML-Soroban/ZKML-Soroban/blob/main/SECURITY.md). |
| Code of Conduct concerns | Follow the reporting steps in the [code of conduct](https://github.com/ZKML-Soroban/ZKML-Soroban/blob/main/CODE_OF_CONDUCT.md). |
| Contributing | Start with the [contributing guide](https://github.com/ZKML-Soroban/ZKML-Soroban/blob/main/CONTRIBUTING.md). |

## Before opening an issue

- Search existing issues, open and closed.
- Check the [known limitations](https://github.com/ZKML-Soroban/ZKML-Soroban/blob/main/docs/security/known-limitations.md);
  some gaps are already tracked.
- Include the crate versions (`zkml-common`, `zkml-verifier`), your Rust version and your
  operating system.

Maintainers respond on a best-effort basis. ZKML Soroban is pre-1.0 and does not offer paid support.
